# Tarot Zodiac Pocket client

Thư mục này chứa Vue/TypeScript SPA, SQLite web runtime và Android Capacitor host của Tarot Zodiac Pocket.

```powershell
npm install
npm run dev
```

Các lệnh kiểm tra trước khi commit:

```powershell
npm test
npm run db:validate
npm run db:validate:web
npm run db:validate:parity
npm run build
```

Xem [README của dự án](../README.md) để biết trạng thái tính năng, cấu trúc, thiết lập Android, CI và cách xử lý lỗi thường gặp.
